Filter Grid
for Divi 5

An AJAX filterable content grid, built natively for Divi 5. Visitors filter, search and paginate your content without reloading the page.

Try the live demoRead the docs

Coming soon to the Divi Marketplace. Unlimited websites, one year of updates and support.

Everything a filterable grid needs

One module, set up in a minute from the Divi 5 builder.

Native Divi 5 module

Built on the Divi 5 module API. No compatibility mode, so the Divi 4 framework is never loaded and pages stay fast.

Any content, any taxonomy

Posts, pages, projects or your own custom post types, filtered by categories, tags or custom taxonomies.

Buttons or dropdowns

Show filters as buttons with single or multiple selection (AND / OR), or as a compact dropdown.

Live search

An optional search field filters the grid as visitors type.

Three pagination styles

Page numbers, a "Load more" button or infinite scroll.

Shareable URLs

The filter state is saved in the address bar: send a filtered view to someone, and the back button works.

SEO friendly

The first page is rendered on the server, so the content is in the HTML. No empty grid while the page loads.

Full design control

Style every element from the Design tab: filters, active filter, search, cards, image, texts, pagination.

Accessible and secure

Keyboard-friendly filters, results announced to screen readers, signed settings so visitors cannot query other content.

Made for the Divi 5 builder

The builder lists the post types and taxonomies of your site. Every change shows in the live preview.

Requirements

Works with the Divi theme or the Divi Builder plugin.
