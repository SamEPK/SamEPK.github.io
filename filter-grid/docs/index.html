Documentation

Filter Grid for Divi 5 adds one module to the Divi 5 builder: a grid of posts, pages or custom post types that visitors filter, search and paginate without reloading the page. This guide covers installation, every setting and the hooks available to developers.

Requirements

SoftwareVersion
DiviDivi 5, as the theme or the Divi Builder plugin
WordPress6.5 or later (tested up to 7.1)
PHP7.4 or later (tested up to 8.3)

The module is built for the Divi 5 API only. It does not run with Divi 4.

Installation

  1. Download the plugin zip file from your Divi Marketplace account.
  2. In WordPress, go to Plugins → Add New Plugin → Upload Plugin, choose the zip file and click Install Now.
  3. Click Activate.

Updates are delivered through the Divi Marketplace, in your WordPress dashboard, like other Divi products. If Divi 5 is not active, the plugin shows a notice and the module stays hidden until it is.

Add the module to a page

  1. Open a page with the Divi 5 builder.
  2. Click the + button in a column and search for Filter Grid.
  3. In Content → Source, choose the post type to show.
  4. In Content → Filters, tick the taxonomies visitors can filter by.
  5. Choose a pagination style, adjust the design, then save the page.

The preview in the builder is rendered by the same code as the live page, so what you see is what visitors get. The module also works inside Divi Theme Builder templates.

Filtered URLs

When a visitor filters or searches, the address in the browser changes, so a filtered view can be bookmarked or shared, and the back button returns to the previous view.

ParameterMeaningExample
d5fg_<taxonomy>Selected terms of a taxonomy, by slug, comma-separated?d5fg_category=news,events
d5fg_sSearch words?d5fg_s=coffee
d5fg_pagePage number (page numbers style only)?d5fg_page=2

Taxonomy names are shortened in the URL: category becomes d5fg_cat and post_tag becomes d5fg_tag. Page links are real links, so they keep working without JavaScript.

Performance and caching

  • The first page of results is rendered in PHP, inside the page HTML. Search engines see the content and visitors never see an empty grid.
  • The stylesheet and script (about 16 KB together, no jQuery) load only on pages that use the module.
  • Query results are cached for one hour, and the cache is cleared whenever content is published, updated or deleted.
  • Caching plugins are supported: if a cached page carries an expired security token, the grid still loads its results.

Accessibility

  • Filters are buttons with aria-pressed, usable with the keyboard.
  • The number of results is announced to screen readers after each change.
  • "Load more" moves the focus to the first new item. Each "Read more" link includes the item title for screen readers.

Example: hide an internal post type from the Source list.

add_filter( 'd5fg_post_types', function ( $types ) {
    unset( $types['my_internal_type'] );
    return $types;
} );

JavaScript event

Each grid dispatches d5fg:updated after new results are shown. event.detail holds the current state (terms, search, page) and the total number of results.

document.addEventListener( 'd5fg:updated', function ( event ) {
    console.log( event.detail.total + ' results' );
} );

REST endpoint

Results are loaded from /wp-json/d5fg/v1/query. The module settings travel in a token signed by your site, so visitors cannot change the post type or read content that the grid does not show. Drafts, private and password-protected posts are never returned.

FAQ

Does it work with Divi 4?

No. The module is written for the Divi 5 API, which is why it does not need the Divi 4 compatibility mode.

Can I use it with WooCommerce products or custom post types?

Yes. Every public post type appears in the Source list, including products and post types created with a plugin or in code. Filters on product attributes and price are planned.

Can I filter by custom fields (ACF)?

Not in version 1.0: filters use taxonomies. Ordering by a custom field is supported (Order By → Custom field). Filters on ACF fields are planned.

Can I put several grids on one page?

Yes. Each grid works on its own. If two grids filter the same taxonomy, they share its URL parameter.

The grid shows "No results found" but I have content.

Check that the selected taxonomies belong to the chosen post type, that the items are published, and that they are not listed in Exclude IDs.

Is it translated?

The front-end texts are translation ready, with English and French included. The builder settings are in English.
